# Curso de Back-end com Python

Coleção curada de exercícios e desafios desenvolvidos durante meu curso de back-end em Python.

## Conteúdos

- Programação orientada a objetos e herança
- Tratamento de erros e validação
- Sistemas interativos em linha de comando
- Interfaces gráficas com Tkinter
- Persistência de dados com SQLite
- Aplicação web do desafio integrado

Este repositório contém somente exercícios de autoria própria selecionados pelo valor técnico. Anotações pessoais, materiais fornecidos pelo professor, imagens, bancos locais e arquivos compactados não foram publicados.
